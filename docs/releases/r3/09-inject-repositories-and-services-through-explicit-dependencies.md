# Inject repositories and services through explicit dependencies


## See the idea first

## Build the public contract

Dependency injection supplies services from outside a route, like Spring constructor injection. FastAPI `Depends` wires the edge; handlers must not construct repositories.

<ApiWorkbench />

## Write the failing contract first

Write a failing route test with an overridden in-memory repository. Create then list a 22K ring and prove both requests use it. Domain code still depends on Protocols, not FastAPI.
